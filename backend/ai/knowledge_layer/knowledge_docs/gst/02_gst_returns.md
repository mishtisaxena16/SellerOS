# GST Returns

## Purpose

GST Returns report sales, purchases, tax liability, and Input Tax Credit (ITC).
---

## Common GST Returns

| Return | Purpose |
|---------|---------|
| GSTR-1 | Outward Supplies |
| GSTR-3B | Monthly Summary Return |
| GSTR-4 | Composition Scheme |
| GSTR-5 | Non-Resident Taxpayer |
| GSTR-6 | Input Service Distributor |
| GSTR-7 | TDS Return |
| GSTR-8 | E-Commerce Operator |
| GSTR-9 | Annual Return |

---

## Late Filing

Late filing may result in:

- Interest on unpaid tax
- Late fees
- Penalties

---

## Input Tax Credit (ITC)

ITC allows businesses to reduce GST liability using tax already paid.
Conditions:
- Supplier files return
- Invoice matches
- Tax is paid

---

## ITC Matching

GST system compares:

Supplier GSTR-1
↓
Recipient GSTR-2
↓
ITC Validation

If mismatch occurs:

- ITC may be reversed.
- Clarification may be required.
---
## Return Revision

Returns cannot be revised directly.
Errors are corrected in subsequent returns.
---
## Best Practices

- File before due date.
- Match invoices regularly.
- Verify supplier compliance.
- Maintain records.
