# Meesho Product Upload & Image Guide

## Overview

This guide explains how to upload products on Meesho using the bulk upload template. It covers mandatory fields, recommended fields, image guidelines, validation checks, supported attributes, and example catalog entries.

---

# Product Upload Template

Meesho supports bulk product uploads using an Excel template.

The template consists of two categories of fields:

- **Mandatory Fields** – Required for catalog approval.
- **Recommended Fields** – Improve listing quality and customer experience.

---

# Mandatory Fields

The following information must be provided for every product:

- SKU ID
- Product ID / Style ID
- Product Name
- Product Variation (Size/Color)
- Meesho Selling Price
- GST Percentage
- HSN Code
- Product Weight
- Country of Origin
- Color
- Material
- Pack Size
- Packaging Dimensions
- Packaging Unit
- Weight Unit
- Front Product Image

Missing or incorrect mandatory fields may result in catalog rejection.

---

# Recommended Fields

Recommended fields improve search visibility and customer trust.

Examples include:

- Brand Name
- MRP
- Inventory Quantity
- Pattern
- Product Dimensions
- Group ID
- Additional Product Images

---

# Bulk Upload Guidelines

Before uploading a catalog:

- Fill all mandatory fields correctly.
- Selling Price must be lower than MRP.
- Ensure all image links are valid.
- Map images to the correct products.
- Avoid spelling and grammatical mistakes.
- Do not use restricted keywords.
- Upload each product variation as a separate row.

---

# Product Variants

Each product variation must have its own row.

Examples:

- Different sizes
- Different colors
- Different pack sizes

Related variants should share the same Product ID / Style ID where applicable while maintaining unique SKU IDs.

---

# Catalog Validation Checklist

Before submitting a catalog, verify:

- All mandatory fields are completed.
- Selling Price is less than MRP.
- Image links are working.
- Images are mapped correctly.
- Product information is accurate.
- No spelling or grammar mistakes.
- No restricted keywords.
- Product variants are uploaded separately.

---

# Restricted Keywords

Avoid using:

- Smoking-related words
- Other marketplace names
- Violent or offensive slogans
- Misleading promotional claims

Listings containing restricted keywords may be rejected.

---

# Image Requirements

Each SKU must include at least one front-facing image.

---

# Accepted Image Standards

Images should:

- Show only the product.
- Use a clean background.
- Clearly display the product.
- Maintain original proportions.
- Be high resolution.

---

# Image Rejection Reasons

Images may be rejected if they contain:

- Text overlays
- Watermarks
- Brand logos
- Blurry images
- Pixelated images
- Inverted images
- Distorted or stretched images
- Cluttered backgrounds
- Partial product visibility
- Offensive or objectionable content
- Props that distract from the product

---

# Image Format Requirements

Supported:

- JPEG (.jpg / .jpeg)

Supported Color Space:

- RGB

Unsupported:

- CMYK
- Other color spaces

---

# Image Upload

Images should be uploaded using the Meesho Supplier Panel Image Uploader.

Supported source:

- Meesho Image Uploader

Not supported:

- Google Drive links
- Unsupported external image links

# Best Practices

To improve catalog approval:

- Upload high-quality product images.
- Use accurate product titles.
- Complete recommended fields wherever possible.
- Verify pricing before submission.
- Use correct HSN codes.
- Ensure inventory information is accurate.
- Follow Meesho image standards.
- Avoid prohibited keywords.
