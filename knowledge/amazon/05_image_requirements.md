# Amazon Image Requirements

## Overview

Product images are critical for listing approval, discoverability, and conversion on Amazon. Sellers must follow Amazon's image quality, background, framing, and AI disclosure requirements.

---

## Main Image Requirements

The primary product image (Main Image / Slot 1) must comply with strict Amazon standards.

### Background

- Must use a pure white background.
- RGB value must be exactly 255, 255, 255.
- Off-white, grey, patterned, or transparent backgrounds are not allowed.

### Image Size

- Minimum: 1500 pixels on the longest side.
- Recommended: 2000–3000 pixels.
- Maximum file size: 10 MB.

### Product Framing

- Product should occupy at least 85% of the image area.
- Excessive white space around the product should be avoided.

### Main Image Restrictions

The main image must not contain:

- Text overlays
- Watermarks
- Logos
- Promotional badges
- Graphs or charts
- Multiple views of the same product
- Props not included with the product
- Visible mannequins (except where specifically permitted)
- Packaging that may confuse buyers about included contents

Failure to follow these requirements may result in listing suppression.

---

## AI Image Disclosure Requirements

Amazon requires sellers to accurately disclose how product images are created.

### Traditional Photography

- Images captured using standard photography.
- Basic editing such as color correction and lighting adjustments is permitted.

### AI-Assisted Images

Examples:

- Real product photographed and placed into an AI-generated background.
- AI-enhanced lifestyle scenes using actual product photos.

### Fully AI-Generated Images

- Product images created entirely using generative AI tools.
- No physical photography involved.

### Compliance Requirement

Sellers must accurately declare image creation methods during listing submission.

Incorrect AI disclosure may lead to:

- Listing suppression
- Compliance reviews
- Account audits

---

## Secondary Image Guidelines

Secondary image slots (typically Slots 2–9) allow more flexibility.

### Allowed Content

- Product infographics
- Feature highlights
- Usage instructions
- Dimension charts
- Comparison charts
- Lifestyle photography
- Text overlays
- Product benefits

### Best Practices

Use secondary images to:

- Explain key features
- Demonstrate product usage
- Display measurements and dimensions
- Highlight materials and specifications
- Answer common buyer questions visually

---

## India Marketplace Recommendations

For products sold in India, consider including:

- Localized size charts
- Clothing fit references
- Shoe size conversion charts
- Product dimensions shown on Indian models
- Usage examples relevant to Indian customers

Providing clear sizing and measurement information can help reduce returns and improve customer satisfaction.

---

## Key Takeaways

- Main images must have a pure white background.
- Minimum image size should be 1500px.
- Product should occupy at least 85% of the image frame.
- Main images cannot contain text, watermarks, or promotional content.
- AI-generated and AI-assisted images must be properly disclosed.
- Secondary images should be used to communicate features, dimensions, and usage information.
