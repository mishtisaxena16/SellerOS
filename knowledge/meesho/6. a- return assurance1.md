# Return Assurance Program

## Overview

The Return Assurance Program (RAP) is a seller protection service designed to reduce the financial impact of high return rates by reimbursing eligible return shipping costs.

---

## Sample Calculation

Example:

- Previous month's return rate: **15%**
- Return coverage for current month: **15–22%**
- Estimated refund on return shipping fees: **Up to ₹605**
- Estimated monthly subscription fee: **0.8% of monthly sales revenue**
- Estimated net savings: **Up to ₹505**

> **Note:** This is an illustrative example provided by Meesho. Actual coverage, refunds, and subscription fees depend on the seller's assigned cohort, sales revenue, and return rate.

---

## Seller Benefits

The Return Assurance Program helps sellers by:

- Protecting against unexpected increases in return shipping costs.
- Providing predictable operating expenses through a subscription model.
- Reducing the financial impact of high return rates.
- Automatically processing eligible compensation.
- Allowing sellers to focus on business growth without manually filing claims.
